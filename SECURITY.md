# Security policy

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this
repository. Do not open a public issue for it.

Include what is affected (package, function, version or commit), how to reproduce it and what an
attacker gains. You get an answer within a week. Fixes go to the latest version only.

This module is used by the karga CLI (github.com/hasankaradmir/karga-cli) and karga-server
(github.com/hasankaradmir/karga-server); a report about either belongs in their repository.
